### **Answer the following questions** 
**What is a graphical user interface (GUI)?**
- A GUI lets you interact with a computer through its visual elements.
**What is a desktop environment?**
- A desktop environment is a complete GUI package for linux and unix-like systems.
**What is the command line interface (CLI)?**
- A CLI is a text-based way to control a computer.
**How do I access the command line interface (CLI)?**
- You can access your CLI through a terminal emulator.
**What is a virtual console?**
- A Virtual Console is a text-based interface that allows for multiple independent login sessions on the same computer.
**What is a terminal emulator?**
- A terminal emulator is a GUI application that gives you a command line window inside your desktop.
**What is bash?**
- Bash is the most widely used linux shell that provides interactive access to the linux system.
**What is the shell prompt?**
- A shell prompt is the text shown before your cursor, indicating the shell is ready for a command. For example:"rap@cis106:~$ "

Definition, usage, and examples of the following commands:

- clear - clears the terminal screen Ex: `clear`
- echo - prints text. Ex:`echo "Hello World!"`
- date - shows or sets the system date and time. Ex:`date`
- free - displays memory usage. Ex: `free -h`
- uname - prints system and kernel information. Ex:`uname -a`
- history - lists or re-runs past commands you've run before. Ex:`!!`,`history`
- man - opens a command's full manual page. Ex: `man date`
- tldr - provides short, simplified and practical chest sheets for command line tools.Ex:`tldr`
- cheat - shows a list of cheat sheets for different commands. Ex:`cheat uname`
- hostname -shows or sets the computer's network name. Ex:`hostname -I`
- df - reports the amount of free disk space. Ex:`df -h`
- du - estimates the disk space used by files and directories. Ex:`du -h cis106`
- figlet - turns text into ASCII-art banners. Ex:`figlet Hello`
